# カイコの塔(仮)

Unity 6で制作中の2Dスタイリッシュローグライクシューティング

## 🚀 主な機能・特徴

* ダッシュやブリンクを駆使して敵の攻撃を避けながら部屋ごとの敵を殲滅していく
* ST,MPや”疲労度”といったステータスに気を配りながら階層の攻略をしていく
* 敵を倒すとで手に入れたEXPをステータスに割り振り、スムーズに選択する
* ”代償”を払うことでそれに見合った”対価”を入手し、自分にあった攻略スタイルを確立していく
